# WORLD BREAKER — 세계 건물 부수기

원래 명세: [docs/WORLD_BREAKER_MVP_SPEC.md](docs/WORLD_BREAKER_MVP_SPEC.md) (이후 요청으로 데스크톱 우선·막대 인간·다국어·건물 시리즈·층별 강도·버티기를 반영).

한 페이지짜리 HTML5 2D 아케이드 파괴 액션 게임입니다. 경복궁에서 부르즈 할리파까지 8개 도시를 돌며, 머리 위로
천천히 내려오는 만화풍 랜드마크를 아래에서 조각조각 부수고, ↓로 버티고, 붉게 빛나는 잔해를 피하고,
SUPER 게이지를 채워 **FULL BREAK!** 로 남은 건물을 통째로 무너뜨립니다.

- **데스크톱 웹 우선**: 1280×800 가로 화면(16:10), 키보드 조작. 터치 기기에서는 화면 버튼이 나타납니다.
- **다국어**: 한국어(기본) · English · 日本語 · 中文. 브라우저 언어로 자동 선택, 타이틀/일시정지에서 변경(`world-breaker-lang`에 저장).
- **주인공**: 코드로 그리는 단순한 파란 막대 인간(달리기·주먹·버티기·피격 포즈 애니메이션).

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 생성 + 유출 검사
npm test           # vitest 단위 테스트
```

에셋은 이미 `public/assets/`에 들어 있으므로 **API 키 없이도 바로 실행됩니다.**

## 조작

| 행동 | PC (원작 키루비루 배치) | 터치 |
|---|---|---|
| 좌우 이동 | `←` `→` | ◀ ▶ 누르고 있기 |
| 점프 | `↑` | ▲ |
| 방어 (건물 잠시 멈춤 + 떨어지는 돌 튕겨내기) | `↓` | ▼ |
| 공격 (칼, 누르고 있으면 연속) | `Z` | 공격 |
| 필살기 (게이지 100%) | `X` | BREAK! |
| 일시 정지 | `Esc` / `P` | 우상단 Ⅱ |

`WASD`, `J`(공격), `K`(필살기)도 같은 동작을 하는 보조 키입니다.

멀티터치 지원: 이동 버튼을 누른 채로 공격할 수 있습니다. 탭이 숨겨지거나 창이 포커스를 잃으면 자동으로 일시 정지됩니다.

## 게임 규칙

- **도시마다 건물 시리즈**: 한 도시에서 같은 랜드마크를 여러 채 연달아 부숩니다. 높이가 높을수록 채 수가 적습니다
  (경복궁·콜로세움 10, 타지마할 9, 빅 벤 7, 롯데월드타워·도쿄 타워·에펠탑 6, 부르즈 할리파 5). 홀수 번째 건물은 좌우 반전되고
  강도 배치도 매번 새로 섞입니다. 한 채를 부술 때마다 `+300 × 스테이지 배수`.
- **층마다 약한 곳·중간·단단한 곳**: 모든 층(행)에 1타(무늬 없음), 2타(주황 줄무늬), 3타(철판 해칭 + 리벳) 조각이 최소 하나씩
  섞입니다. 표시는 원화 픽셀 위에만 그려지고(철골 사이 하늘에는 안 칠함) 맞을 때마다 단계가 내려갑니다(3→2→1).
- **내려오는 건물**: 건물은 주인공 머리 위에 떠서 천천히 내려옵니다(도시별 11~22px/s, 시리즈 뒤쪽일수록 조금 빠름).
  가장 아래 남은 조각이 머리 높이에 닿으면 하트 -1, 건물은 위로 튕겨 올라갑니다. 아래층을 부술수록 바닥이 올라가 여유가 생깁니다.
- **방어(↓)**: 방어 게이지 30을 써서 건물을 1.2초 멈추고 살짝 밀어 올리며, 0.45초 동안 떨어지는 돌을 튕겨냅니다. 초당 12씩 회복.
- **칼은 머리 바로 위(좌우 60px, 위로 80px)까지만 닿습니다.** 그 범위에서 가장 아래 조각을 벱니다. 건물이 높으면 `↑`로 점프(최고 약 200px)해서 밑바닥을 베고, 건물 밑면에 머리가 닿으면 더 올라가지 않습니다. 범위에 조각이 없으면 헛손질(점수·게이지 없음).
- 조각 파괴 `+100 × 콤보 배수 × 스테이지 배수`, 균열만 냄 `+20 × 스테이지 배수`.
- 1.5초 안에 다시 맞히면 콤보. 배수 `min(1 + floor((combo-1)/4) × 0.25, 3)`.
- 적중마다 필살기(SUPER) 게이지가 오르고, **콤보가 높을수록 빨리 찹니다**(5콤보마다 ×0.5, 최대 ×3). 스테이지 1은 명세대로 +8%(13회면 가득), 이후 도시는 6·5·5·4·4·3·3%로 줄어
  필살기를 아껴 쓰게 됩니다. 게이지는 다음 건물·스테이지로 이어지고, 사용하면 0이 됩니다.
- 땅과 연결이 끊긴 작은 덩어리는 250ms 흔들린 뒤 아래 조각부터 차례로 떨어집니다(`+40`/조각). 시작 시 조각 수의 30%가 넘는
  큰 덩어리는 떨어지지 않으므로 한 방에 건물 대부분이 사라지지 않습니다.
- FULL BREAK!: 남은 조각 전부를 아래에서 위로 약 0.75초에 걸쳐 실제로 분리합니다(`+50`/조각, 이미 부서진 조각은 0점).
  발동 중에는 무적입니다.
- 위험 잔해: 붉은 외곽선 + 바닥 `!` 예고. 공중으로 튀어 오른 뒤 떨어지고, 생성 후 0.35초 동안은 판정이 없습니다.
  맞으면 하트 -1, 1.25초 무적. 스테이지 1은 8%(첫 8초 0%, 튜토리얼), 스테이지 8은 22%.
- 도시(시리즈) 클리어 보너스 `+1200 × 스테이지 배수`, 그 도시에서 한 번도 안 맞으면 `+500`. 최고 기록은 `localStorage`(`world-breaker-best-score`)에 저장.

| # | 랜드마크 | 건물 수 | 그리드 | 위험 잔해 | 중간/단단 비율 | 하강 px/s | SUPER/타 | 점수 배수 |
|---|---|---|---|---|---|---|---|---|
| 1 | 경복궁 근정전 | 10 | 12×6 | 8% | 25% / 8% | 11 | 8 | 1.0 |
| 2 | 롯데월드타워 | 6 | 5×12 | 10% | 30% / 10% | 13 | 6 | 1.1 |
| 3 | 도쿄 타워 | 6 | 5×12 | 12% | 30% / 12% | 14 | 5 | 1.2 |
| 4 | 에펠탑 | 6 | 5×12 | 13% | 32% / 14% | 16 | 5 | 1.3 |
| 5 | 빅 벤 | 7 | 5×12 | 16% | 34% / 16% | 17 | 4 | 1.4 |
| 6 | 콜로세움 | 10 | 12×6 | 17% | 34% / 18% | 19 | 4 | 1.5 |
| 7 | 타지마할 | 9 | 12×7 | 20% | 36% / 20% | 20 | 3 | 1.6 |
| 8 | 부르즈 할리파 | 5 | 5×14 | 22% | 38% / 24% | 22 | 3 | 2.0 |

유효 조각이 25개 미만이면 그리드가 자동으로 더 촘촘해집니다.

## 파괴 엔진 (src/game/Building.ts, Destruction.ts)

1. 건물 원화(투명 WebP)의 알파를 작은 캔버스에서 한 번 샘플링해 셀별 실제 픽셀 비율을 구합니다. 6% 미만 셀은 조각이 아닙니다.
2. 그리드의 모든 내부 꼭짓점과 변 중점을 시드 기반으로 한 번만 흔들어 **이웃 조각이 같은 톱니형 경계를 공유**합니다.
   그래서 처음 상태는 틈 없이 원화 한 장처럼 보입니다.
3. 조각이 아닌 성긴 셀 중 아트가 걸칠 수 있는 셀은 가장 가까운 조각에 합쳐지고, 나머지는 레이어에서 지워집니다.
   어떤 픽셀도 주인 없이 남지 않으므로 고스트가 생기지 않습니다.
4. 화면에는 원화에서 만든 **건물 레이어 한 장**만 그립니다. 조각이 부서지면 그 조각의 정확한 다각형을 레이어에서
   `destination-out`으로 지워 뒤의 하늘이 보이게 하고, 미리 잘라 둔 그 조각의 이미지를 회전·낙하하는 파편으로 넘깁니다.
5. 상태 전환 `intact/damaged/unsupported → fallen`은 `BreakModel.destroy()` 한 곳에서만 일어나고 정확히 한 번만 `true`를
   반환합니다. 일반 공격·연쇄 붕괴·필살기가 같은 프레임에 겹쳐도 점수는 한 번입니다.
6. 클리어는 정적 조각(`intact/damaged/unsupported`) 수가 0일 때. 떨어지는 장식 파편은 클리어를 막지 않습니다.

게임 루프는 1/60초 고정 스텝(프레임 dt 최대 0.1초 클램프)이라 저속 프레임에서도 물리·판정이 같습니다.
시각 파편 최대 100개, 위험 잔해 최대 12개. 효과음은 Web Audio로 합성하며 동시 발음 수와 같은 소리의 재생 간격을 제한합니다.
`prefers-reduced-motion`이면 화면 흔들림과 섬광이 줄어듭니다.

## xAI 에셋 파이프라인 (개발 시에만)

게임은 플레이 중 **어떤 AI API도 호출하지 않습니다.** 랜드마크 8종과 배경 8종은 개발 단계에서 xAI `grok-imagine-image-2.0`로
생성해 파일로 저장했습니다. 배경은 데스크톱 가로 화면용으로 16:9(2k)로 다시 생성했습니다(`--all --type=background --force`).

주인공은 요청에 따라 단순한 막대 인간으로 바꾸어 코드로 그립니다. 처음 생성한 일러스트 주인공 3포즈 원본은
`art-source/character/`에 남아 있고(`--with-hero`로만 다시 생성), 게임에는 포함되지 않습니다.

```bash
cp .env.example .env               # XAI_API_KEY=... (Node 스크립트만 읽음, .gitignore 처리됨)
npm run assets:generate -- --sample                 # 경복궁 건물 + 서울 배경
npm run assets:generate -- --all                    # 8 건물 + 8 배경 (있는 파일은 재사용)
npm run assets:generate -- --all --type=background --force   # 배경만 전부 다시
npm run assets:generate -- --id=eiffel_tower --type=building --force   # 하나만 다시
npm run assets:process             # 마젠타 크로마키 → 투명 WebP, 트림, 리사이즈
npm run assets:validate            # 존재/디코딩/해상도/알파/불투명 비율/마젠타 테두리/총 용량 검사
npm run assets:preview             # art-preview.html + art-source/contact-sheet.png
```

- 프롬프트: `scripts/prompts.mjs` (공통 STYLE ANCHOR + 건물/배경/캐릭터 템플릿).
- 원본은 `art-source/`(저장소 용량 때문에 내려받은 뒤 WebP q93으로 재인코딩), 게임용 결과는 `public/assets/{buildings,backgrounds}/`.
- 요청마다 ID, 프롬프트, 모델, 시각, 저장 위치, 규격, 성공 여부를 `public/assets/assets-manifest.json`에 기록합니다(키는 기록 안 함).
- 이미 있는 파일은 덮어쓰지 않습니다(`--force`만 예외). 실패 시 최대 2회 재시도(지수 backoff, 4xx는 재시도 안 함).
- 실행 전에 예상 호출 수와 비용을 출력하고 `MAX_ASSET_REQUESTS`(기본 30), `MAX_ASSET_BUDGET_USD`(기본 3) 초과 시 중단합니다.
  비용은 `COST_PER_IMAGE_1K_USD`/`COST_PER_IMAGE_2K_USD`로 조정하는 **보수적 추정치**이며, 실제 가격은 xAI 가격표를 확인하세요.
- (선택) `--with-hero`일 때 `hero_attack`, `hero_hit`은 `hero_idle`을 참조 이미지로 `POST /images/edits`를 호출해 같은 캐릭터로 맞춥니다.
- 응답의 바이트를 매직 넘버로 확인해 실제 형식(PNG/JPEG/WebP)대로 저장합니다. URL 응답이면 즉시 내려받고, 게임은 xAI URL을 쓰지 않습니다.

`vite.config.ts`는 `envPrefix: 'WB_PUBLIC_'`이라 `XAI_API_KEY`가 클라이언트 코드에 노출될 수 없고, `npm run build`는 마지막에
`scripts/check-dist.mjs`로 `dist/`에 키 값, `XAI_API_KEY`, `api.x.ai`, `images/generations`, `images/edits`, `b64_json`, `Bearer`가
없는지 검사해 하나라도 있으면 빌드를 실패시킵니다.

## 새 스테이지 추가

1. `scripts/prompts.mjs`의 `LANDMARKS`에 항목 추가 → `npm run assets:generate -- --id=<id>` → `assets:process` → `assets:validate`.
2. `src/game/StageConfigs.ts`의 `STAGES`에 `StageConfig`를 추가합니다(`breakGrid`, `hazardRate`, `toughShare`, `debris`,
   `scoreMultiplier`). 엔진 코드는 바꿀 필요가 없습니다. P1 후보(`sydney_opera_house`, `statue_of_liberty`,
   `leaning_tower_pisa`, `taipei_101`)는 `RESERVED_STAGE_IDS`에만 있고 에셋이 없으므로 순환에 들어가지 않습니다.
