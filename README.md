# WORLD BREAKER — 건물 부수기

고전 《斬るビル》(키루비루, '건물 부수기')에서 영감을 받은 단일 페이지 HTML5 아케이드 게임입니다.
하늘에서 세계 랜드마크가 한 채씩 떨어지고, 닌자가 거대한 칼로 맨 아래층의 좌·중·우 세 레인 중 약한 곳을 베어
**층 전체**를 무너뜨립니다. 엔드리스 모드, 목숨 3개, 6단계 난이도.

명세: [docs/building_breaker_spec.md](docs/building_breaker_spec.md) (v1.0). 이전 명세는 [docs/WORLD_BREAKER_MVP_SPEC.md](docs/WORLD_BREAKER_MVP_SPEC.md).

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # dist/ + 유출 검사
npm run build:single   # dist-single/index.html (이미지까지 모두 내장한 단일 파일)
npm test               # vitest
```

API 키나 서버 없이 실행됩니다. 모든 이미지는 `public/assets/`의 정적 파일입니다.

## 규칙 (모든 수치는 `src/config/balance.ts` 한 곳에)

- 건물 = 층 여러 개 × 레인 3개. 각 칸 HP 1(금 간 곳) / 2(보통) / 3(금테 철판). **한 레인이 0이 되면 그 층 전체가 사라지고**
  위층은 그대로 남아 계속 떨어집니다. 맨 아래층 밑의 칩이 레인별 남은 타격 수를 보여 줍니다(설정에서 숫자 표시 가능).
- 적중마다 건물이 7 밀려 올라가고, 층이 없어지면 그 높이만큼 바닥이 올라갑니다. 건물이 땅(y=530)에 닿으면 하트 -1,
  그 건물은 사라지고 1.25초 무적 후 다음 건물.
- **지상 가드**: 게이지 30, 85 밀어냄, 낙하속도 ×0.30, 콤보 0. **공중 가드**(점프 중): 게이지 18, 35 밀어냄, ×0.55, 콤보 유지(+0.45초).
  가드는 건물이 땅 95 이내일 때만 닿고, 게이지가 모자라면 GUARD BREAK.
- 콤보 1.5초, 배수 `min(3, 1 + floor(combo/5)×0.25)`. 점수: 적중 10×배수, 층 `(100 + 층번호×5)×배수`,
  건물 `500 + tier×100 + 층수×20`(엘리트 +300). 필살기 게이지 적중당 `7 + min(8, floor(combo/8)×2)`.
- 필살기(X): 남은 모든 층 즉시 제거(층 점수 65%), 연출 중 무적.
- 난이도는 파괴한 건물 수 기준 6단계(층 3–5 → 12–20, 속도 ×1.0 → 최대 ×2.4, HP3 비율 5% → 50%). 5번째마다 ELITE.
  같은 런 시드면 같은 건물 순서. 최근 2개 랜드마크는 다시 나오지 않습니다.

**명세와 다르게 조정한 값**(명세에서 튜닝 대상으로 둔 구현값): 랜드마크 그림을 알아볼 수 있도록 건물 높이를 랜드마크마다
240–340(층수가 많으면 층당 최소 18)으로 두고, 새 건물은 그 80%가 화면에 보이도록 바닥 y=85–240 사이에서 등장합니다.
명세 값(y=85, 층 높이 18–36)을 그대로 쓰면 높은 랜드마크가 대부분 화면 위에 숨어서 레인 표시가 보이지 않았습니다.

## 게임 손맛 v2 ([docs/game_feel_upgrade_v2.md](docs/game_feel_upgrade_v2.md))

수치는 모두 `src/config/gameFeel.ts` 한 곳에 있습니다. `?debugFeel=1`로 열면 슬라이더·테스트 버튼·이벤트 로그 패널이 나옵니다(개발용).

- **점프**: 이륙 820wu/s, 상승 중력 1650 / 하강 2600 → 최고 약 204wu(캐릭터 키의 3배 이상), 정점 약 0.5초, 체공 약 0.9초.
  짧게 누르면 낮은 점프(0.2초 안에 떼면 속도 ×0.56), 착지 직전 입력 110ms 버퍼, 이륙 늘어남·착지 찌그러짐·먼지.
  건물 밑면은 천장이라 캐릭터가 건물 속으로 들어가지 않습니다.
- **가드 = 접촉 상태기계** `READY → HOLD → REPEL → RELEASE` (아래 v3에서 수치·규칙 갱신): ↓만 누르면 자세만 잡고 건물은 그대로 떨어집니다.
  건물 밑면이 **올려 든 칼(머리 위 8wu)에 실제로 닿는 순간** 그 자리에 멈춰 120ms(공중 110ms) 버티고,
  ease-out으로 지상 85wu / 210ms, 공중 35wu / 160ms **연속 이동**으로 밀어 올린 뒤 80ms에 걸쳐 낙하속도로 돌아갑니다.
  가드 중에는 이 상태기계만 건물 Y를 바꿉니다. 접촉 1회당 게이지 1회 소비, 지상은 콤보 0, 공중은 유지.
- **위험선**: v1의 '땅'에서 '서 있는 캐릭터의 머리 높이(y=468)'로 옮겼습니다. 건물이 캐릭터를 관통해 보이면 안 된다는 v2 요구 때문입니다.
- **공격**: 95ms 주기, 입력한 다음 틱에 판정. 검격 3종(올려베기·반대베기·찌르기)이 번갈아 나옵니다.
  HP 3→2는 먼지·스파크, 2→1은 큰 균열·조각, 1→0은 층 전체 파괴.
- **층 파괴**: 맞은 지점 섬광 → 그 층 그림이 45ms 동안 남아 균열이 좌우로 번짐 → 층 텍스처를 자른 큰 조각 3–6개 + 재질별 파편 12–26개
  + 연기 5–10개 + 충격파, 남은 위층은 렌더 전용으로 4wu 살짝 튀어오름. 재질(유리·석재·철골·목재·혼합)마다 파편 모양과 소리가 다릅니다.
- **히트스톱**은 게임 로직만 멈춥니다(일반 28 / 층 52 / 완파 70 / 필살기 75ms). 파편·카메라는 실제 시간으로 계속 움직입니다.
- **카메라 임펄스**(방향·감쇠, 합산 상한 10)는 월드 레이어에만, HUD는 고정. '이펙트 낮음' 또는 `prefers-reduced-motion`이면 흔들림 0, 파편 140개 상한.
- **배너 우선순위** SPECIAL > FINISH > CLUTCH > CHAIN > COMBO > NORMAL, 동시에 최대 2개: `ONE HIT BREAK!`, `CHAIN CUT!`, `COUNTER!`,
  `AERIAL FINISH!`, `완파!/DESTROYED!`, `CLUTCH!`, 콤보 10 / 25 `RUSH!` / 50 `UNSTOPPABLE!` / 100 `LEGENDARY!`, 0.25초 안 충돌 예측 시 `DANGER`.
  추가 데미지·점수는 없습니다.

브라우저에서 실제로 측정한 값(1366×768, rAF 단위 샘플): 점프 최고 197wu, 지상 가드 정지 145ms(로직 120ms, 샘플링 오차) → 85.0wu / 198ms
→ 복귀 83ms, 공중 가드 정지 113ms → 35.0wu / 166ms → 복귀 84ms, 접촉 순간 건물 밑면과 칼 높이 차 0.00wu.

## 사용자 요청 반영 (v4 이후)

- **점프 높이 제한 없음(건물이 막을 때까지)**: 화면에 건물이 보이면 어떤 점프든(짧게 눌러도) 칼이 그 건물 밑면에 닿을 만큼 뛰어오르고 밑면에서 멈춥니다.
  건물이 없을 때만 기존 점프(약 204wu, 짧게 누르면 낮은 점프).
- **깔리면 건물 밑에 완전히 묻힘**: 목숨 1 감소 후 건물이 땅까지 내려앉아 캐릭터가 보이지 않습니다(v4의 '건물 제거' 대신).
  **Z(공격)**를 누르면 위에 있던 층이 부서지고 건물이 등장 높이까지 높게 튕겨 올라간 뒤 다시 떨어집니다. 마지막 목숨이면 그대로 GAME OVER.
  묻혀 있는 동안 Z 외의 입력은 무시, 목숨은 한 번만 줄고, 탈출로 점수는 없습니다.

## 핫픽스 v4 ([docs/gameplay_hotfix_v4.md](docs/gameplay_hotfix_v4.md)) — v1~v3과 충돌하면 v4가 우선

- **깔림 = 목숨 1개, 그리고 깔끔한 복구**: 같은 틱에 먼저 잠그고(`DAMAGE_IMPACT`) 건물 충돌을 끈 뒤 그 건물을 무너뜨립니다.
  130ms 충격 → 270ms `RECOVER`(캐릭터를 현재 레인 지면으로) → 다음 건물(목숨 0이면 GAME OVER). 이 동안 입력·물리·공격 판정은 없습니다.
  무적 1.25초는 목숨 중복 감소만 막습니다.
- **가드 무제한**: 가드 게이지·소모·회복·준비 시간·잠금·재입력 조건을 모두 없앴습니다. ↓를 누르고 있거나 이번 틱에 눌렀고
  칼(머리 위 8wu)이 실제로 밑면에 닿으면 **항상 성공**(연속 충돌 TOI, 이미 칼을 누르고 있는 건물도 그 자리에서 잡음). 판정 순서는
  필살기 → 가드 → 공격 → 깔림이라 같은 틱이면 가드가 이깁니다. 정지 120ms(공중 100ms) → 36wu/170ms(공중 18wu/140ms) → 70ms 재낙하.
  가드는 점수·콤보·필살기 게이지를 주지 않고, 지상 가드는 콤보를 끊습니다.
- **낙하 속도(절대값, 한 곳에서만)**: 티어 1~6 = 190 / 240 / 300 / 390 / 490 / 600wu/s, 티어 6은 건물마다 +10, 최대 650. 예전 배율은 곱하지 않습니다.
  등장 높이는 티어별 목표 TTC(등장→첫 접촉 1.9 / 1.45 / 1.25 / 0.95 / 0.78 / 0.62초)에 맞춰 정해집니다. 4번째 건물부터 전환 0.3초, 티어가 오르면 `SPEED UP!`.
- **타격 반동 4wu(누적 없음)**. Z를 누르고 있으면 스윙 사이에도 칼이 건물을 받쳐 줘서(피해·점수 없음) 프레임 타이밍 때문에 타격을 놓치지 않습니다.
- **필살기**: 누르는 순간 게이지 0·충돌 끔·점수 1회 지급. 건물은 화면에 그대로 남고, 거대한 검광이 최하층에서 꼭대기까지 실제로 올라가며
  층마다 순서대로 터지고, 화면 위로 넘친 건물은 카메라가 따라 올라갑니다. 꼭대기에서 큰 폭발 → 복귀 → 다음 건물(약 1.0~1.45초).
- **UI**: GUARD 바 삭제. 키 안내는 줄바꿈되지 않는 칩 한 줄로 시작 후 4초만 보이고(좁은/낮은 화면에선 숨김), 전체 목록은 `?`/일시정지 메뉴에.
  힌트는 화면 아래쪽, DANGER는 캐릭터 옆 작은 글씨. `?debug=1` 또는 F3: 단계·Y 소유자·속도·TTC·가드 입력·피격 횟수 오버레이.

브라우저 실측(1280×720): 티어 1 등장→가드선 접촉 1.90초; 650wu/s에서 ↓를 3초 누르고 있기 → 7번 모두 접촉 간격 0.00wu로 가드, 목숨 감소 0;
깔림 중 Z 연타 → 타격 0; 필살기(3층) 꼭대기 도달 583ms, 다음 건물 1016ms; 562×419·360×640·390×844·1280×720에서 키 안내 칩 줄바꿈 0, HUD 잘림 0.

## 접촉 판정 v3 ([docs/contact_combat_guard_v3.md](docs/contact_combat_guard_v3.md))

v3가 공격·가드 판정에서는 v1/v2보다 우선합니다. `?debugContact=1`로 열면 접촉면 선·간격 수치·TOI·가드 상태 패널이 나옵니다.

- **공격은 실제로 닿을 때만**: 공격 포즈의 칼 윗면(머리 위 12wu)과 현재 레인의 최하층 밑면 사이 간격이 **2wu 이하(관통 3wu까지)**일 때만 HP가 줄어듭니다.
  매 틱 이전/현재 간격으로 **연속 충돌(TOI)**을 계산해서 빠른 낙하에도 접촉을 건너뛰지 않고, 그 순간의 레인 위치로 **수평 겹침**도 확인합니다.
  멀리서 Z를 누르면 칼은 휘두르지만 HP·콤보·점수·필살기·타격음·파편·히트스톱·흔들림은 0입니다.
- **스윙 1회 = 최대 1타**. 탭 스윙은 55ms, Z를 누르고 있을 때의 연속 스윙은 다음 스윙까지(95ms) 칼이 살아 있습니다(빈틈 없이 접촉을 잡기 위한 선택).
  입력 버퍼 70ms.
- **맞은 건물은 그 자리에서 멈췄다가**(속도 0, 7wu 반동) 다시 칼 위로 떨어집니다(가속 3000wu/s²). 그 7wu 틈이 닫히기 전엔 맞지 않습니다.
  층이 부서지면 다음 층은 실제로 떨어져서 다시 닿아야 하고, 그동안 최대 400wu/s로 빠르게 내려오다가 마지막 26→6wu에서 원래 속도로 줄어듭니다.
- **가드**: ↓를 **새로 누르면** 180ms 동안 READY. 그 안에 칼(머리 위 8wu)과 밑면이 실제로 닿으면 성공, 아니면 손을 뗄 때까지 LOCKED(멀리서 계속 누르기 = 무적 아님).
  일찍 뗀 입력도 누른 뒤 70ms 안의 접촉이면 인정. 성공하면 **충돌 시점의 위치에서** 건물이 즉시 멈추고(남은 낙하는 버림)
  지상 120ms / 공중 100ms 정지 → smootherstep으로 **지상 36wu / 170ms, 공중 18wu / 140ms** 밀어 올림 → 70ms 동안 0 → 낙하속도.
  정지·반발·복귀 중에는 가드만 건물 Y를 바꾸고, 그동안은 공격 판정이 없습니다. 게이지는 접촉 1회당 한 번(지상 30 / 공중 18).
- **우선순위**: 필살기 → 가드 접촉 → 공격 접촉 → 위험선(머리). 같은 프레임 Z+↓면 가드가 이깁니다.
- **그림 = 판정**: 공격·가드 포즈는 칼 윗면이 정확히 판정선에 오도록 그립니다(공격 포즈는 xAI로 다시 생성: 칼을 머리 바로 위로 수평 베기).
  최하층 밑면에는 세 레인을 가로지르는 띠를 판정선에 맞춰 그리고, 그 아래로 삐져나온 그림은 잘라냅니다. 카메라 흔들림은 캐릭터와 건물에 같이 적용됩니다.
- 가드 충격 연출은 낙하 속도에 비례(시각만): 흔들림 2.5–4px, 스파크 5–10개, 소리 음높이 1.0→0.92.

브라우저 실측(1280×720, 60Hz): 건물 80wu 위에서 Z 1초 → 스윙 11회·명중 0; Z를 누르고 있을 때 명중 간격 0.58–1.92wu;
2.4배 낙하(276wu/s)에서 마지막 순간 지상 가드 → 접촉 간격 0.00wu, 정지 133ms(120ms를 1/60초 틱 단위로 올림), 반발 183ms; 공중 가드 정지 100ms;
100wu 위에서 ↓ 0.7초 유지 → LOCKED, 건물 이동·접촉 0.

## xAI 에셋 (개발 시에만)

게임은 플레이 중 AI API를 호출하지 않습니다. 이미지는 개발 단계에서 xAI `grok-imagine-image-2.0`으로 만들었습니다.

```bash
cp .env.example .env   # XAI_API_KEY=... (Node 스크립트만 읽음, gitignore)
npm run assets:generate -- --all      # 없는 것만 생성 (기존 파일 재사용, --force로 재생성)
npm run assets:process                # 크로마키 → 투명 WebP
npm run assets:validate               # 30개 파일 검사
```

- 생성된 정적 에셋: 건물 13, 도시 배경 8 + 하늘 3(낮/노을/밤), 필살기 컷인 1, **닌자 5포즈**(대기·공격·점프·가드·피격 —
  대기 그림을 참조 이미지로 `images/edits` 호출해 같은 캐릭터 유지). 총 xAI 호출 46회, 실패 0.
- 프롬프트는 `scripts/prompts.mjs`, 요청 기록은 `public/assets/assets-manifest.json`(키 없음).
- `npm run build`는 `dist/`에 키 값·`api.x.ai`·`images/generations`·`b64_json`·`Bearer`가 있으면 실패합니다.
